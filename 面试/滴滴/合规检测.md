背景：开国合规
检查是否有隐私敏感相关权限 方法被调用。检查是否有写死的IP地址，品牌标识等。
敏感方法：mac地址获取，deviceId获取，敏感权限：查找所有app，读取 短信，读取 通话记录。

实现：新增一个 gradle plugin，同时创建一个新的task。

- task 的主要功能
  - 依赖 javaCompile 方法来实现的
  - hook mergeManifest 这个task，获取输入路径，对权限进行查找匹配
  - 使用javassist 对 class 文件进行 字符串匹配，方法调用匹配，看看是否有业务开申请了某些权限。字符串查找通过匹配常量池的值来查找。方法调用则是遍历所有的 method，调用其 instrument 方法，来分析方法体，里面获取MethodCall来获取被调用的类和方法。
  - 对于 SO 文件和资源文件，进行字符串查找，其中so文件使用 readelf 进行查找 read only data 部分，包括字符串常量这些。 

task 功能分为三部分。

- 查找class文件中的内容
读取javaCompile的outPut路径和classPath路径，将所有的类加载出来。
- 根据config文件配置，初始化内容，进行遍历查找
- 依据查找结果输出到文件。
